[abstract]
== Abstract

[%unnumbered]
image::figures/3DTiles_dark_color_small.png[]

This document describes the specification for 3D Tiles, an open standard for streaming massive heterogeneous 3D geospatial datasets.

== Preface

Bringing techniques from graphics research, the movie industry, and the game industry to 3D geospatial, 3D Tiles defines a spatial data structure and a set of tile formats designed for 3D, and optimized for streaming and rendering.

== Relationship to glTF

A 3D Tiles 2.0 tileset is a glTF 2.1 asset. The `3DTILES_tileset` extension is a normative part of the 3D Tiles 2.0 specification and defines the structure of the tileset. Specifically, the `3DTILES_tileset` extension defines:

* The hierarchical structure of the tileset, including the `children` of a tile.
* The tile object, which represents a node in the tileset hierarchy.
* The definition of a tile's content, including its URI and bounding volume.
* The geometric error and refinement strategy (`ADD` or `REPLACE`) for each tile.
* The transformation of a tile.
* How application-specific _metadata_ may be included at multiple granularities using the 3D Metadata Specification.
* The mechanism for linking to external tilesets.

All tile content is represented as glTF assets, either embedded or external.

Any feature that is normatively defined in the glTF 2.1 specification is considered a normative part of 3D Tiles 2.0. A conforming 3D Tiles 2.0 implementation SHOULD support all normative features of glTF 2.1 unless otherwise stated.
