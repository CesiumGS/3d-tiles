[abstract]
== Abstract

[%unnumbered]
image::figures/3DTiles_dark_color_small.png[]

This document describes the specification for 3D Tiles, an open standard for streaming massive heterogeneous 3D geospatial datasets.

== Preface

Bringing techniques from graphics research, the movie industry, and the game industry to 3D geospatial, 3D Tiles defines a spatial data structure built on glTF designed for 3D, and optimized for streaming and rendering.

== Relationship to glTF

A 3D Tiles 2.0 tileset is a glTF 2.1 asset. The link:{gltf-ext-3dtiles_tileset-url}[3DTILES_tileset] extension is a normative part of the 3D Tiles 2.0 specification and defines the structure of the tileset. Specifically, the link:{gltf-ext-3dtiles_tileset-url}[3DTILES_tileset] extension defines:

* The hierarchical structure of the tileset.
* The tile object, which represents a tile in the tileset hierarchy.
* The definition of a tile's content, including its URI.
* The geometric error and refinement strategy (`ADD` or `REPLACE`) for each tile.
* The mechanism for supporting implicit tiling.
* The mechanism for linking to external tilesets.
* The coordinate reference system of the tileset.
* The mechanism for assigning application-specific _metadata_ using the 3D Metadata Specification.

All tile content is represented as glTF assets, either embedded or external.

Any feature that is normatively defined in the glTF 2.1 specification is considered a normative part of 3D Tiles 2.0. A conforming 3D Tiles 2.0 implementation SHOULD support all normative features of glTF 2.1 unless otherwise stated.
